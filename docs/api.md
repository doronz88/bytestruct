# API reference

Everything below is importable from `bytestruct` (the exceptions also from `bytestruct.exceptions`).

::: bytestruct
    options:
      show_root_heading: false
      show_root_toc_entry: false
      # The exceptions are documented once, under bytestruct.exceptions below.
      filters: ["!^_", "!Error$"]

::: bytestruct.exceptions
